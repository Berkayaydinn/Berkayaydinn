### About me

My strengths are API design, relational data modeling, and integration testing. I work with Python, Java, and SQL to define how services exchange data, enforce consistency in the database, and verify that a request produces the expected result.

I also build and evaluate machine learning models. I use confusion matrices to understand classification errors and experiment with loss functions to see how training decisions affect predictions. I'm interested in backend and data infrastructure roles.
