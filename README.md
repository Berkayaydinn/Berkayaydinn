### About me

My strengths are API design, relational data modeling, and integration testing. I work with Python, Java, and SQL to define how services exchange data, enforce consistency in the database, and verify that a request produces the expected result.

I also build and evaluate machine learning models. I use confusion matrices to understand classification errors and experiment with loss functions to see how training decisions affect predictions. I'm interested in backend and data infrastructure roles.

### Selected work

- **[BioSetLab Workbench](https://github.com/Berkayaydinn/biosetlab-workbench)** · A collaborative research project building an AI-assisted, no-code platform for biomedical data analysis. Our team integrated Ollama/Qwen to transform natural-language requests into structured, executable analysis workflows. I worked on AI workflow integration, connecting LLM-generated graphs to a React Flow editor, managing node and edge state with Zustand, and validating workflow compatibility. We evaluated the system through biomedical classification experiments, including the Breast Cancer Wisconsin dataset.
- **[Machine Learning Experiments](https://github.com/Berkayaydinn/machine-learning-experiments)** · Four experiments in classification and regression. I analyzed Gaussian Naive Bayes errors on 300 CIFAR-10 images, explored logistic regression and convolutional networks, and tested how a custom loss function affected vehicle-price predictions.
- **[Road Safety FTR](https://github.com/kanikeliff/road-safety-ftr)** · A video inference pipeline our research team at Istanbul Technical University built for a road-safety competition. I integrated a fine-tuned Florence-2 vision-language model into the pipeline, which groups frame-level detections into events and exports validated JSON.
- **[Nuvio AI](https://github.com/kanikeliff/Mental-health-app)** · Our team built an iOS app for mood tracking and mental health assessments. We used FastAPI and Firebase to score assessments, summarize weekly mood entries, and save reports to each user's account. All 23 backend tests passed, and we verified report creation and storage with the Firebase emulators.
- **Mirabito Wholesale Billing Portal** · Our team built a portal for Mirabito to review fuel deliveries against their bills of lading. I worked on PostgreSQL schemas, migrations, and constraints that link billing records to source documents and reviewer decisions. I also tested the database and helped deploy the portal on Railway.
